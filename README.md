# Krishnanand Yadav — 3D Holographic Digital Personal Card

A futuristic, mobile-first 3D holographic personal identity card and interactive photo hub built with HTML5, Tailwind CSS, and 3D Canvas node-connect animations.

## Features
- **3D Interactive Node-Connect Flow Background**: Real-time 60fps interactive particle network.
- **3D Tilt Hologram Personal ID Card**: Interactive tilt glare, laser scanline, and downloadable `.vcf` contact card.
- **Live In-Frame Photo Shifter**: Shifts all 7 personal frames (`16:9` and `9:16` auto-corrected) directly inside the main hologram stage without external page redirects.
- **100% Serverless (Zero Database)**: Runs completely in the browser.

## Live Deployment (GitHub Pages)
1. Upload `index.html` and `README.md` to your GitHub repository.
2. Go to **Settings -> Pages**, select the `main` branch, and click **Save**.
